# Changelog

## v0.1.0

- First release: the `runzivo` OpenHands skill. It creates, connects to, checks, stops, starts and deletes Runzivo sandboxes through `rzv` 0.26.0 or newer, and asks before deleting.
- `bin/rzv-openhands-backend`: an OpenHands Agent Server 1.60.1 in a Runzivo sandbox, reached over an SSH tunnel as an Agent Canvas or SDK remote backend.
